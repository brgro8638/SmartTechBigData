# SmartTechBigData

Hub repository for assignments in:

- **DTE-2804 Smart Teknologi**
- **DTE-2803 Store datasystemer (Big Data)**

## Structure

- `/BACKLOG.md` contains the complete numbered assignment backlog.
- `/subjects/dte-2804-smart-teknologi/` is the root folder for Smart Teknologi assignment files.
- `/subjects/dte-2803-store-datasystemer/` is the root folder for Big Data assignment files.

## Folder naming convention for assignments

Use one folder per assignment with assignment number in the name:

- `A01-embedded-system`
- `A02a-cabac-presentation`
- `A02b-huffman-gui`

This keeps all files easy to find and aligned with assignment numbering.
